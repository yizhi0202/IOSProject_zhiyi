# ✅ 解决方案：speedscope 显示具体时间数值

## 问题

之前在 speedscope 中只能看到**比例**，看不到**具体的时间数值**（如 2000ms）。

## 解决方案 🎯

**核心改进：** 将采样次数转换为**微秒(μs)**，speedscope 会自动识别并显示为具体时间！

### 转换公式

```
微秒数 = 采样次数 × 采样间隔(秒) × 1,000,000
```

### 实际例子

```
采样次数: 40 次
采样间隔: 50ms = 0.05秒
转换结果: 40 × 0.05 × 1,000,000 = 2,000,000 微秒

speedscope 显示: 2.00 s 或 2000 ms ✅
```

### 在 speedscope 中的显示

1. 复制数据粘贴到 speedscope.app
2. speedscope 自动将微秒转换：
   - `2000000 μs` → 显示为 `2.00 s` 或 `2000 ms`
   - `1000000 μs` → 显示为 `1.00 s` 或 `1000 ms`
   - `500000 μs` → 显示为 `500 ms`
3. 鼠标悬停在火焰图的任意条上，即可看到具体的时间数值！

## 代码实现

### 修改的关键代码

```objc
// SuperProject/Classes/基础理论/常用实践/火焰图原理/SUPSimpleFlameGraph.m

/// 递归导出节点（输出微秒数，speedscope 会显示为时间）
- (void)exportNode:(KSStackNode *)node path:(NSString *)path output:(NSMutableString *)output {
    // ... 其他代码 ...
    
    if (node.children.count == 0) {
        // 叶子节点：输出完整路径和时间（微秒）
        // 公式：微秒 = 采样次数 × 采样间隔(秒) × 1,000,000
        NSUInteger microseconds = (NSUInteger)(node.sampleCount * self.samplingInterval * 1000000);
        [output appendFormat:@"%@ %lu\n", currentPath, (unsigned long)microseconds];
    } else {
        // 计算自身消耗
        NSUInteger selfSamples = node.sampleCount - childrenSamples;
        if (selfSamples > 0) {
            // 输出自身耗时（微秒）
            NSUInteger microseconds = (NSUInteger)(selfSamples * self.samplingInterval * 1000000);
            [output appendFormat:@"%@ %lu\n", currentPath, (unsigned long)microseconds];
        }
        // ... 递归处理子节点 ...
    }
}
```

## 常见问题

### Q1: 数字太大了正常吗？

**正常！** 数字是微秒单位：
- `2000000` = 2,000,000 微秒 = 2000 毫秒 = 2 秒
- speedscope 会自动转换显示，不用担心

### Q2: 如何在 speedscope 中看到具体数值？

**方法1：** 鼠标悬停在火焰图的任意条上  
**方法2：** 查看 speedscope 右侧的详细信息面板

### Q3: 还能用其他方式查看吗？

**可以！** 控制台还会输出两种格式：

1. **详细统计表格**（`printDetailedStatistics`）
```

==========================================================================
main;viewDidLoad;fetchData;networkRequest      40     2000.00     40.00%
```

2. **带时间注释的格式**
```
main;viewDidLoad;fetchData;networkRequest 40  (2000.00 ms)
```

## 技术原理

### 为什么使用微秒？

1. **speedscope 支持**：speedscope 能自动识别微秒单位
2. **精度够高**：微秒可以表示毫秒级的时间
3. **整数表示**：避免浮点数精度问题
4. **自动转换**：speedscope 自动显示为可读格式（ms、s）

### 转换逻辑

```
原始数据：采样次数（无单位）
      ↓
转换公式：次数 × 间隔 × 1,000,000
      ↓
输出数据：微秒数（μs）
      ↓
speedscope 识别：自动转换为 ms 或 s 显示
```
