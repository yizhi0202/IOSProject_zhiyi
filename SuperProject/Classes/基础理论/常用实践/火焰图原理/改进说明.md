# 火焰图功能增强说明 🔥

## 改进概览

本次更新增强了火焰图采样器的数据可视化能力，现在可以在控制台和 speedscope 中看到**具体的 ms 数值**，而不仅仅是比例。

## 主要改进

### 1. 添加采样间隔记录 ⏱️

**文件：** `SUPSimpleFlameGraph.m`

**改动：**
```objc
@interface SUPSimpleFlameGraph ()
// ... 其他属性
@property (nonatomic, assign) NSTimeInterval samplingInterval;  // ✨ 新增
@end

- (void)startSamplingWithInterval:(NSTimeInterval)interval {
    // ...
```

**作用：**
- 保存采样间隔，用于后续计算实际耗时
- 公式：实际耗时 = 采样次数 × 采样间隔

### 2. 新增详细统计输出 📊

**新方法：** `printDetailedStatistics`

**输出示例：**

**特性：**

- ✅ 便于直接在控制台定位性能瓶颈

### 3. 增强火焰图导出格式 🔥

**提供两种导出格式：**

#### 标准格式（兼容 speedscope）⭐
**方法：** `exportToFoldedStackFormat`

```
main;viewDidLoad;fetchData;networkRequest 40
main;viewDidLoad;setupUI;layoutViews 20
```

**特性：**
- ✅ 纯数字格式，完全兼容 speedscope.app
- ✅ 可以直接粘贴查看火焰图

#### 带时间注释格式（供查看）
**方法：** `exportToFoldedStackWithTimeComments`

```
main;viewDidLoad;fetchData;networkRequest 40  (2000.00 ms)
main;viewDidLoad;setupUI;layoutViews 20  (1000.00 ms)
```

**特性：**
- ✅ 包含具体的 ms 数值，方便查看
- ⚠️ 不兼容 speedscope（仅供参考）

## 技术细节

### 时间计算公式

```
实际耗时（ms） = 采样次数 × 采样间隔（ms）
```

**示例：**
```
采样次数: 40
采样间隔: 50ms
实际耗时: 40 × 50 = 2000ms = 2秒
```

### 精度说明

⚠️ **这是估算值，不是精确测量**

**影响因素：**
- 采样间隔越小，精度越高
- 函数执行时间需 > 采样间隔，才能被准确捕捉
- 极短的函数调用（< 1ms）可能被漏掉

**建议：**
- 用于宏观性能分析（找热点）✅
- 不适合微观性能测量（精确计时）❌
- 想要精确计时请用 `CFAbsoluteTimeGetCurrent()` 或 Instruments
